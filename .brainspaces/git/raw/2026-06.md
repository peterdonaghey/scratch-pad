## 2026-06-08T10:01:48Z
**PR #2:** feat: short shared URLs via Upstash Redis (replace ?md= with ?id=) (MERGED)
**Author:** peterdonaghey  **Branch:** feat/short-urls-upstash-redis → main
**Files:** 12 files, +313/-262 lines

Closes #1

## Summary

Replaces the old `?md=` URL scheme (which stuffed the entire markdown into the URL) with a short `?id=\) scheme backed by Upstash Redis.

## What changed

- **`api/url.mjs`** — POST only. Stores content in Upstash Redis with a `crypto.randomUUID()` ID (7-day TTL), returns `?id=` URL
- **`api/content.mjs`** — NEW. GET endpoint to retrieve stored content by ID
- **`src/storage.ts`** — Removed `parseMdFromUrl()`, `buildScratchPadUrl()`, `?md=` from `getInitialState()\)
- **`src/App.tsx`** — `useEffect` fetches content from API when `?id=\) present, Copy URL button now uses API, loading/error states
- **`src/index.css`** — Loading dots animation for remote content fetch
- **`SKILL.md` / `README.md`** — Clean docs, no legacy `?md=\) references
- Removed `url-for-pad.js` and `url-generator.html` (legacy tools)

## Deviations from original issue

- Legacy `?md=\) support removed entirely (not just deprecated) per discussion
- Copy URL button now makes an API call instead of building a local URL
- Legacy local tooling removed

## Deployment

Deployed and verified live on `scratch-pad-beryl.vercel.app`:

```
POST /api/url { "md": "# Test...", "name": "demo" }
→ { "url": "https://scratch-pad-beryl.vercel.app/demo?id=1fb46fac-1663-49ab-85e1-55f3175a61ba" }
```

## Summary

Adds a **My Sheets** slide-over panel that lists all saved scratch pads from localStorage. Users can see what they've saved, open sheets, and delete them.

## What changed

- **`src/SheetsPanel.tsx`** — NEW. Slide-over panel (same pattern as Styles) listing all saved sheets with title, snippet preview, last-saved time, and Open/Delete actions
- **`src/storage.ts`** — Added `listSavedSheets()`, `deleteSheet()`, `SheetInfo` interface. `saveToStorage()` now stamps `savedAt` timestamp. Helpers extract title (first `# heading`) and plain-text snippet from markdown
- **`src/types.ts`** — Added `savedAt?: number` to `ScratchPadState`
- **`src/App.tsx`** — Added "My Sheets" button in the top bar, wired up panel state
- **`src/index.css`** — Card layout, snippet truncation, action buttons for sheet list

## Design

- Unnamed sheet listed first (unless it's the default welcome page — skipped)
- Named sheets sorted alphabetically by title
- Open navigates to `/<name>` or `/` for unnamed — full page load re-reads from localStorage
- Delete prompts confirm, then removes from localStorage and refreshes the list
- Empty state shows a help message
